\title{BioDINO-Edge: Gradient-Free Cascades of Frozen Vision Foundation Models for On-Device Few-Shot Plant Disease Diagnosis}

\author[1]{Reyhane Javidi Alsaadi\corref{cor1}}
\ead{reyhane.code@gmail.com}

\author[1]{Mohammad Reza Samadzadeh}
\ead{samadzadeh@ut.ac.ir}

\cortext[cor1]{Corresponding author}

\affiliation[1]{organization={Department of Computer Engineering, Dr. Shariaty Technical University},
                city={Tehran},
                country={Iran}}

\begin{abstract}
Deploying few-shot plant disease diagnosis at the edge is constrained by scarce labeled samples, cluttered field backgrounds, and edge processors that cannot support iterative backpropagation. We present \textbf{BioDINO-Edge}, a gradient-free diagnostic framework that adapts frozen vision foundation models directly on device without network connectivity. Instead of fine-tuning backbones, it combines DINOv2 lesion-contour features with BioCLIP taxonomic embeddings aligned to botanical text descriptions in an 896-dimensional space. To isolate subtle foliar lesions from shared vegetative backgrounds under scarce reference samples, BioDINO-Edge constructs regularized Fisher linear discriminant projections via analytical Ledoit--Wolf shrinkage. This closed-form formulation solves one-time parameter adaptation across novel pathologies in 0.53\,s on an edge processor without gradient computation. At inference, an uncertainty gate combining normalized Shannon entropy and top-2 margin routes routine foliage through a 59.78\,ms Tier-1 fast path ($\approx$16.7 frames per second), escalating ambiguous queries to a 164.52\,ms multimodal Tier-2 that transductively recalibrates projections using high-confidence predictions. Across 30 episodes on 11-class PlantVillage, BioDINO-Edge achieves 97.41\% $\pm$ 0.71\% accuracy (97.09\% macro F1) with a 0.79\% $\pm$ 0.36\% false-negative disease rate. On in-the-wild PlantDoc foliage, it reaches 84.22\% $\pm$ 11.24\% in 5-way 5-shot testing and 50.79\% in 27-way evaluation. The complete system is deployed as an Android application whose diagnostic classification operates entirely on-device without network connectivity, enabling reliable in-field diagnosis without cloud dependence.
\end{abstract}

\begin{highlights}
\item Fuses frozen DINOv2 and BioCLIP encoders for on-device plant disease diagnosis.

\end{highlights}

\section{Introduction}
\label{sec:intro}
Early identification of foliar plant diseases is critical for timely agricultural intervention, reducing crop losses and preventing unnecessary pesticide application \cite{richard2022control,shafik2023systematic}. Because foliar lesions can spread rapidly across agricultural canopies, manual scouting by agronomists is labor-intensive, subjective, and difficult to sustain across large fields \cite{shoaib2023advanced}. Automated vision systems offer a scalable alternative, but their heavy reliance on large labeled datasets remains a primary limitation \cite{shoaib2023advanced}.

Deep learning architectures, including convolutional neural networks (CNNs) and vision transformers (ViTs), achieve strong performance on standardized crop pathology benchmarks. However, conventional supervised models require thousands of labeled images per class \cite{shoaib2023advanced}. In agricultural practice, new pathogen variants, regional strains, and early-stage lesions provide only scarce and imbalanced data. As a result, standard training pipelines adapt poorly to rapidly evolving field conditions.

Few-shot learning (FSL) addresses this limitation by adapting models to novel classes from only one to five labeled examples per pathology \cite{sun2024few}. Metric-based FSL approaches classify query leaves by computing distances to support prototypes in a learned representation space \cite{zhao2024mafde}. However, standard distance metrics (such as Euclidean distance or cosine similarity) treat feature coordinates uniformly, making predictions vulnerable to non-discriminative background variance such as leaf veins and glare \cite{yang2024laboratory,kudo2025few}. While parameter-efficient fine-tuning (PEFT) and optimization-based meta-learning can establish discriminative boundaries, they require iterative backpropagation, optimizer state memory, and autograd execution, exceeding the compute and thermal budgets of mobile edge processors \cite{babu2025agrifewnet}.

Existing edge diagnosis methods face two primary limitations. First, models are rarely tested on edge hardware, often relying on server-grade graphics processing units (GPUs) without reporting latency, proportional set size (PSS) memory footprint, or thermal slowdown on resource-constrained processors \cite{radocaj2025evolution}. Second, standard few-shot classifiers return uncalibrated softmax scores that do not convey predictive uncertainty, producing overconfident errors on ambiguous lesions \cite{sharif2026real}. Without uncertainty-aware routing, automated scouting systems risk making incorrect treatment decisions or missing critical infections.

We therefore introduce BioDINO-Edge, a gradient-free, two-tier cascaded few-shot framework designed for edge execution. The architecture couples a fast Tier-1 visual encoder (8-bit integer (INT8) quantized DINOv2-Small \cite{oquab2023dinov2}) with a deeper Tier-2 biological encoder (INT8-quantized BioCLIP \cite{stevens2024bioclip}) within a joint 896-dimensional space. To minimize computational latency, a dual-metric Shannon entropy and margin gate evaluates Tier-1 confidence, allowing clear leaves to exit early while routing uncertain queries to the deeper Tier-2 model. Adaptation to novel pathologies is computed analytically through regularized Fisher Linear Discriminant Analysis (Fisher-LDA) \cite{fisher1936use} paired with Ledoit--Wolf covariance shrinkage \cite{ledoit2004well}, achieving one-time closed-form parameter adaptation in 0.53\,s on a mobile central processing unit (CPU) without backpropagation. We package the complete system into a standalone Android application package (APK) that executes fully offline on device with low memory overhead.

The primary contributions of this work are:
\begin{enumerate}
    \item \textbf{Closed-form, gradient-free edge adaptation:} We formulate few-shot foliar adaptation as a closed-form algebraic solution using analytical Ledoit--Wolf covariance shrinkage and regularized Fisher-LDA projections. This enables novel foliar pathologies to be registered on resource-constrained mobile CPUs in 0.53\,s without iterative backpropagation, autograd graphs, or optimizer tuning.
    \item \textbf{Uncertainty-gated cascaded inference:} We design a dual-metric confidence gate (normalized Shannon entropy and top-2 margin) that routes clear foliage to a low-latency Tier-1 fast exit while reserving multimodal consensus for ambiguous queries. By routing 14.02\% of queries through the 59.78\,ms fast path, the cascade reduces average inference latency from 164.52\,ms to 149.84\,ms while preserving 97.41\% accuracy. Transductive recalibration yields an additional +2.33 percentage points in accuracy without gradient computation.
    \item \textbf{Physical edge benchmarking:} We test dual-foundation inference on an ARM64 mobile CPU without GPU acceleration, evaluating end-to-end latency, memory footprint ($<$500\,MB PSS), and sustained continuous throughput (settling at 4.26 frames per second [FPS]).
    \item \textbf{Field-domain evaluation with target-domain support:} On PlantDoc, combining the botanical text prior with regularized visual features over the same frozen encoders reaches 84.22\% $\pm$ 11.24\% in the 5-way 5-shot protocol and 50.79\% across all 27 classes, with support drawn from the PlantDoc training split and no backbone fine-tuning.
\end{enumerate}

The remainder of this paper is organized as follows. Section~2 reviews related work in agricultural few-shot learning, transductive inference, and edge cascades. Section~3 presents the physical system setup, mathematical notation, and theoretical preliminaries. Section~4 details the proposed BioDINO-Edge methodology, including closed-form regularized Fisher-LDA adaptation and the two-tier uncertainty cascade. Section~5 describes the experimental setup, benchmark datasets, and hardware profiling testbed. Section~6 reports benchmark comparisons, statistical significance tests, component ablations, computational latency, and robustness evaluations. Section~7 discusses operational deployment considerations and practical limitations, and Section~8 concludes the paper with future directions.

\section{Related Work}
\label{sec:related_work}

\subsection{Few-Shot Learning in Plant Pathology}
Automated foliar pathology frequently encounters novel disease strains and regional pathogen variants with limited labeled samples \cite{shoaib2023advanced,sun2024few}. Metric-based few-shot learning frameworks address this constraint by mapping query images to support prototypes within a learned metric space \cite{snell2017prototypical,wang2019simpleshot}. Recent agricultural studies have tailored metric architectures to crop foliage: Zhao et al.~\cite{zhao2024mafde} introduced multiscale attention mechanisms (MAFDE-DN4) to capture localized foliar lesions, Yang et al.~\cite{yang2024laboratory} investigated cross-domain meta-learning to bridge laboratory leaves and field samples, and Mu et al.~\cite{mu2024few} applied supervised contrastive learning (SC-FSL) to separate visually subtle pathologies. Similarly, Kudo et al.~\cite{kudo2025few} explored metric domain adaptation, and Babu et al.~\cite{babu2025agrifewnet} introduced AgriFewNet for foliar few-shot classification.

Standard metric approaches still rely primarily on unweighted distance metrics, such as Euclidean distance or cosine similarity. Because these formulations weight all feature dimensions uniformly, they remain vulnerable to background clutter from healthy foliage, leaf veins, and variable lighting \cite{yang2024laboratory,kudo2025few}. In addition, optimization-based meta-learning methods (e.g., MAML \cite{finn2017maml}) require iterative gradient updates during adaptation, which incurs high memory and computational overhead unsuited to edge processors \cite{babu2025agrifewnet,radocaj2025evolution}.

\subsection{Frozen Foundation Models and Parameter-Efficient Adaptation}
The emergence of large vision and vision--language foundation models pretrained on extensive datasets has shifted the few-shot paradigm from training from scratch toward adapting fixed feature representations. Self-supervised vision transformers such as DINO \cite{caron2021emerging} and DINOv2 \cite{oquab2023dinov2} yield rich local patch representations without label supervision, whereas multimodal models such as CLIP \cite{radford2021clip} and domain-specific variants like BioCLIP \cite{stevens2024bioclip} align visual features with taxonomic botanical hierarchies.

To transfer these foundation representations without full backbone retraining, various parameter-efficient fine-tuning strategies have emerged, including prompt tuning (CoOp \cite{zhou2022coop}), Low-Rank Adaptation (LoRA \cite{hu2022lora}), and non-parametric key--value caches (Tip-Adapter \cite{zhang2022tip}). While PEFT reduces updated parameter counts, gradient-based methods still demand backward passes, optimizer state allocations, and autograd graphs, which exceed the compute and thermal budgets of agricultural edge processors \cite{babu2025agrifewnet}. Non-parametric caching models such as Tip-Adapter eliminate gradient steps but weight all visual tokens equally, omitting class-conditional covariance structure. Although classical statistical methods such as Fisher discriminant analysis \cite{fisher1936use} and Ledoit--Wolf shrinkage \cite{ledoit2004well} provide well-conditioned, closed-form projections under small sample sizes, their application to adapting frozen visual foundation models on edge hardware remains largely unstudied in plant pathology.

\subsection{Transductive Few-Shot Inference and Its Batch Requirement}
Transductive few-shot methods leverage the query set itself, rather than only the support set, and currently achieve the strongest published accuracy in training-free settings \cite{boudiaf2020transductive,ziko2020laplacian}. LaplacianShot \cite{ziko2020laplacian} regularizes predictions with a graph Laplacian term that encourages queries with similar embeddings to share the same class label. TIM \cite{boudiaf2020transductive} instead optimizes query logits for confident, class-balanced predictions. BD-CSPN \cite{liu2021bdcspn} attributes prototype error to an intra-class and a cross-class bias, and corrects both, by label propagation over the query set and by shifting query features toward the support distribution.

All three methods share a key requirement: the pairwise graph, class margins, or feature shifts must be computed over the entire query batch simultaneously. While effective for offline benchmarks evaluated on a fixed image pool, this setup is poorly suited to real-time agricultural deployments where a handheld device or field robot evaluates leaf samples sequentially as they are acquired.

\subsection{On-Device Edge Cascades and Uncertainty Routing}
Deploying vision models directly on edge platforms, such as robotic smart sprayers, handheld scouting terminals, and agricultural aerial vehicles, requires bounded latency, low memory footprints, and minimal heat buildup \cite{radocaj2025evolution,sharif2026real}. To balance accuracy and efficiency, cascaded architectures and selective classification frameworks dynamically adjust computational effort per query \cite{geifman2017selective,traub2024overcoming}. In selective classification, samples exceeding a confidence threshold are classified quickly by an initial stage, whereas uncertain queries are escalated to deeper computational pipelines \cite{geifman2017selective,traub2024overcoming}. BioDINO-Edge builds on this principle by introducing an on-device cascade that gates leaf queries based on predictive uncertainty.

\subsection{Positioning BioDINO-Edge}
In plant pathology, existing systems typically direct every leaf query through a single, static neural pipeline and generate uncalibrated softmax scores \cite{sharif2026real,zhao2026lightweight}. This introduces two practical shortcomings: routine, clear leaves waste latency and energy on unnecessary full evaluation, while ambiguous lesions risk confident misclassifications, potentially causing chemical over-application or undetected disease spread. BioDINO-Edge resolves this tension by combining frozen foundation backbones, closed-form shrinkage projections, and uncertainty-gated routing. Rather than running a deep multimodal pipeline on every frame, our architecture verifies Tier-1 prediction certainty via normalized Shannon entropy and top-2 margin and escalates only challenging leaves, achieving high diagnostic reliability within strict edge resource budgets.

\section{Problem Formulation and Engineering Preliminaries}
\label{sec:problem_formulation}

\subsection{Sequential Edge Few-Shot Task Formulation}
\label{sec:task_formulation}
Field diagnosis requires identifying crop diseases directly on mobile devices as leaves are inspected in the field. When deployed to a new crop or region, the system must calibrate using only a small reference set of labeled leaves collected on site:
\begin{equation}
    \mathcal{S} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{N_s}, \qquad N_s = C \times K
\end{equation}
where $C$ is the number of target pathology classes (e.g., $C \in \{5, 11, 27\}$) and $K$ is the number of labeled examples per class (typically $K = 5$). These local diseases are unseen during pre-training ($\mathcal{Y}_{\text{base}} \cap \mathcal{Y}_{\text{novel}} = \emptyset$).

During active scouting, leaves are observed sequentially as an online stream:
\begin{equation}
    \mathcal{Q}_{\text{stream}} = \{\mathbf{x}_t\}_{t=1}^{T}, \qquad \mathbf{x}_t \in \mathbb{R}^{H \times W \times 3}
\end{equation}
The system must output an immediate diagnosis $\hat{y}_t \in \{1, \dots, C\}$ for each incoming frame $\mathbf{x}_t$, without buffering queries or waiting for future images.

Performing this diagnosis on edge hardware faces strict computational limits. Fine-tuning deep backbones on device requires extra memory and causes processor slowdown. Our model therefore relies on frozen foundation encoders ($\nabla_\theta = \emptyset$). We extract complementary visual and biological features using DINOv2-Small ($d_1 = 384$) and BioCLIP ($d_2 = 512$), yielding a fixed joint descriptor $\mathbf{z} \in \mathbb{R}^d$ ($d = 896$) without gradient calculations during field adaptation.

\subsection{Engineering and Operational Constraints}
\label{sec:engineering_constraints}
Because remote crop fields often lack internet connectivity, foliar diagnosis must run entirely on edge devices rather than on cloud servers \cite{shoaib2023advanced}. We define the on-device diagnostic objective as a constrained optimization problem that maximizes accuracy while bounding the disease escape rate (false-negative rate, FNR) and satisfying operational engineering boundaries:
\begin{equation}
\begin{aligned}
    \max_{\mathbf{W}, \mathbf{b}, \, \tau_{\text{conf}}} \quad & \mathbb{E}_{(\mathbf{x}_t, y_t)}\big[\mathbb{I}(\hat{y}_t = y_t)\big] \\
    \text{subject to} \quad & \begin{cases}
        \text{FNR}(\hat{y}) \le \epsilon_{\text{esc}} & \text{(agronomic safety)} \\
        \overline{L}_{\text{inf}}(\tau_{\text{conf}}) \le L_{\max} & \text{(real-time stream latency)} \\
        T_{\text{adapt}}(\mathcal{S}) \le T_{\max}, \; \nabla_\theta = \emptyset & \text{(gradient-free calibration)} \\
        \text{Mem}_{\text{PSS}} \le M_{\max} & \text{(mobile thermal and memory budget)}
    \end{cases}
\end{aligned}
\label{eq:constrained_objective}
\end{equation}
where $\mathbf{W} \in \mathbb{R}^{C \times d}$ and $\mathbf{b} \in \mathbb{R}^C$ denote the analytical projection parameters, and $\tau_{\text{conf}}$ governs the two-tier escalation gate.

While the exact operational parameters $(\epsilon_{\text{esc}}, L_{\max}, T_{\max}, M_{\max})$ depend on the scouting platform and target crop pathology, we establish representative target boundaries for our edge deployment:
\begin{enumerate}
    \item \textbf{Agronomic Disease Escape Limit ($\text{FNR} \le \epsilon_{\text{esc}}$):} In plant protection, misclassifying an infected leaf as healthy allows pathogens to spread across the field unnoticed. Under integrated pest management principles \cite{richard2022control}, preventing secondary infection outbreaks requires minimizing missed infections. We therefore target an FNR below $\epsilon_{\text{esc}} = 1.0\%$.
    \item \textbf{Real-Time Stream Latency ($\overline{L}_{\text{inf}} \le L_{\max}$):} Field scouting platforms require continuous scanning to inspect crop canopies. Maintaining an inspection rate of $\ge 6$ frames per second requires mean per-frame latency to remain within $L_{\max} = 170$\,ms to prevent buffer overflow and dropped frames \cite{sharif2026real}.
    \item \textbf{Sub-Second On-Device Calibration ($T_{\text{adapt}} \le T_{\max}$):} When encountering a new regional pathogen variant in the field, calibrating the model with a few reference leaves ($K=5$) must finish within sub-second time ($T_{\max} \le 1.0$\,s) so scouting can resume immediately. In addition, backpropagation and optimizer tracking are disallowed on device ($\nabla_\theta = \emptyset$) to prevent memory bloat and processor slowdown.
    \item \textbf{Memory Footprint ($\text{Mem}_{\text{PSS}} \le M_{\max}$):} Mobile edge terminals share limited random-access memory (RAM) across the operating system and camera drivers. Setting a budget of $M_{\max} = 500$\,MB peak PSS ensures the diagnostic engine avoids memory-pressure termination and operates safely on fanless embedded hardware.
\end{enumerate}

\subsection{Small-Sample Covariance Degeneracy}
\label{sec:covariance_degeneracy}
Foliar representations exhibit non-uniform feature variance across latent dimensions. Unrelated background patterns---such as green pigmentation, leaf veins, and surface glare---span the highest-variance directions in the feature space. When classification relies on isotropic metrics such as unweighted Euclidean distance or cosine similarity:
\begin{equation}
    \hat{y}_t = \arg\max_{c \in \{1, \dots, C\}} \frac{\mathbf{z}_t^T \boldsymbol{\mu}_c}{\|\mathbf{z}_t\|_2 \|\boldsymbol{\mu}_c\|_2}, \qquad \boldsymbol{\mu}_c = \frac{1}{|\mathcal{S}_c|}\sum_{\mathbf{x} \in \mathcal{S}_c} \mathbf{z}(\mathbf{x})
    \label{eq:isotropic_cosine}
\end{equation}
all feature coordinates are weighted equally ($\mathbf{\Sigma} = \sigma^2 \mathbf{I}$). As a result, distance metrics are dominated by healthy leaf background rather than subtle lesion symptoms.

Fisher Linear Discriminant Analysis resolves this issue by projecting features through the inverse within-class covariance $\hat{\mathbf{\Sigma}}^{-1}$, which suppresses high-variance shared background directions and amplifies discriminative lesion signals. Computing this projection requires the empirical pooled within-class scatter matrix:
\begin{equation}
    \mathbf{S}_W = \frac{1}{N - C} \sum_{c=1}^C \sum_{\mathbf{z} \in \mathcal{S}_c} (\mathbf{z} - \boldsymbol{\mu}_c)(\mathbf{z} - \boldsymbol{\mu}_c)^T \in \mathbb{R}^{d \times d}
    \label{eq:empirical_scatter}
\end{equation}
In field deployment, however, the number of support samples $N$ is far smaller than the feature dimension $d$ ($N \ll d$). Across our target evaluation settings:
\begin{itemize}
    \item In 5-way 5-shot field diagnosis, $N = 25$ versus $d = 896$, yielding $\text{rank}(\mathbf{S}_W) \le 20$.
    \item On the 11-class PlantVillage benchmark without augmentation, $N = 55$ versus $d = 896$, yielding $\text{rank}(\mathbf{S}_W) \le 44$.
    \item Even after multi-view support augmentation ($N = 440$), $\text{rank}(\mathbf{S}_W) \le 429 < 896$.
\end{itemize}
Because $\text{rank}(\mathbf{S}_W) \le N - C \ll d$, the empirical scatter matrix $\mathbf{S}_W$ has nullity $d - (N - C) > 0$. This makes $\mathbf{S}_W$ strictly singular ($\det(\mathbf{S}_W) = 0$) and numerically unstable under simple diagonal loading. This fundamental singularity motivates the analytical shrinkage and uncertainty-gated architecture detailed in Section~\ref{sec:methodology}.

\section{Proposed Methodology: BioDINO-Edge}
\label{sec:methodology}
Building upon the theoretical framework and operational constraints established in Section~\ref{sec:problem_formulation}, BioDINO-Edge addresses few-shot plant disease diagnosis through closed-form discriminative projection over frozen foundation representations, paired with an uncertainty-gated cascaded inference pipeline for resource-constrained edge hardware.

\subsection{Pipeline Overview}
\label{sec:system_architecture}
BioDINO-Edge splits its workflow into an offline analytical calibration phase (Phase~0) and an adaptive two-tier runtime cascade (Phase~1), as shown in Fig.~\ref{fig:architecture}. In Phase~0, a small support set ($K = 5$ labeled leaves per class) is expanded with multi-view augmentation. Features from the frozen DINOv2 and BioCLIP backbones are then used to compute Tier-1 visual prototypes and regularized Fisher-LDA projection weights in closed form, while botanical text prototypes are pre-encoded and cached. At inference (Phase~1), each query first goes through the lightweight Tier-1 DINOv2 encoder. An uncertainty gate lets clear leaves exit immediately and escalates only ambiguous queries to the deeper Tier-2 multimodal stage. High-confidence predictions can then update the Tier-2 projections through background transductive recalibration. Table~\ref{tab:notation} summarizes the mathematical notations and descriptions used across the framework.

\subsection{Dual-Foundation Foliar Representation}
\label{sec:feature_extraction}
BioDINO-Edge couples two frozen backbones. DINOv2 provides patch-level features of leaf surface texture and lesion boundaries, while BioCLIP provides organismal taxonomic priors. Concatenating their $\ell_2$-normalized outputs yields an 896-dimensional descriptor that encodes localized symptoms alongside host context.

\subsubsection{Few-Shot Multi-View Support Augmentation}
To overcome covariance ill-conditioning when reference data are scarce ($K = 5$), each support leaf $\mathbf{x} \in \mathcal{S}_c$ is resized to $224 \times 224$ pixels, normalized, and passed through an 8-view stochastic augmentation pipeline approximating field variations. The pipeline applies random horizontal and vertical flips, rotations within $\pm 15^\circ$, and color jitter (brightness, contrast, and saturation factors of $0.2$). Generating eight views per leaf yields $|\tilde{\mathcal{S}}_c| = 8K = 40$ augmented views per class, producing $N = 40C = 440$ total support representations for $C = 11$. This expansion brings the support sample size close to half the joint feature dimension ($d/2 = 448$), which stabilizes the covariance condition number. Although augmented views are not strictly independent, regularized shrinkage prevents numerical degeneracy and guarantees positive-definiteness.

\subsubsection{Dual-Foundation Embedding Fusion}
Each augmented view $\tilde{\mathbf{x}} \in \tilde{\mathcal{S}}_c$ is passed through the frozen backbones. DINOv2 Small ($14\times 14$ patches) \cite{oquab2023dinov2} and BioCLIP ViT-B/16 \cite{stevens2024bioclip} extract $\ell_2$-normalized feature vectors:
\begin{equation}
    \mathbf{f}_{\text{dino}} = \frac{\phi_{\text{dino}}(\tilde{\mathbf{x}})}{\|\phi_{\text{dino}}(\tilde{\mathbf{x}})\|_2} \in \mathbb{R}^{384}, \qquad
    \mathbf{f}_{\text{bio}} = \frac{\phi_{\text{bio}}(\tilde{\mathbf{x}})}{\|\phi_{\text{bio}}(\tilde{\mathbf{x}})\|_2} \in \mathbb{R}^{512}
\end{equation}
Concatenating the two normalized embeddings yields the 896-dimensional joint descriptor:
\begin{equation}
    \mathbf{z} = [\mathbf{f}_{\text{bio}} \,\|\, \mathbf{f}_{\text{dino}}] \in \mathbb{R}^{896}
\end{equation}
Visual prototypes for the Tier-1 classifier are computed as the normalized mean of the support views:
\begin{equation}
    \mathbf{P}_{\text{dino}}^{(c)} = \text{Normalize}\left(\frac{1}{|\tilde{\mathcal{S}}_c|}\sum_{\tilde{\mathbf{x}} \in \tilde{\mathcal{S}}_c} \mathbf{f}_{\text{dino}}(\tilde{\mathbf{x}})\right)
\end{equation}
yielding the Tier-1 visual prototype matrix $\mathbf{P}_{\text{dino}} \in \mathbb{R}^{C \times 384}$.

\subsubsection{Botanical Taxonomic Prompts and Negation Avoidance}
BioCLIP provides a shared vision--language space, but running text decoders on device costs latency and memory. We therefore define $M = 3$ botanical prompt templates $\{T_c^{(m)}\}_{m=1}^M$ offline for each disease class $c \in \{1, \dots, C\}$. Each template covers three elements:
\begin{enumerate}
    \item \textbf{Host species:} Botanical genus and species (e.g., \textit{Malus domestica}, \textit{Vitis vinifera}, \textit{Solanum tuberosum}).
    \item \textbf{Pathogen name:} Scientific name of the causal agent (e.g., \textit{Venturia inaequalis}, \textit{Guignardia bidwellii}, \textit{Phytophthora infestans}).
    \item \textbf{Visible symptoms:} Diagnostic foliar symptoms (e.g., ``olive-green velvety lesions'', ``tiger-stripe interveinal chlorosis'', ``target-board concentric rings'').
\end{enumerate}
Syntactic negations such as ``healthy leaf without lesions'' or ``no necrotic spots'' are excluded. Vision--language models handle negation poorly \cite{radford2021clip, yuksekgonul2023when, alhamoud2025vision}: content words such as \textit{lesion} and \textit{necrotic} carry far larger $\ell_2$ norm than function words such as \textit{without} or \textit{no}, so the pooled sentence vector of a negated description stays biased toward the disease cluster. Measured with the BioCLIP text encoder over the 11 classes, the three healthy prototypes lie at a mean cosine of 0.695 to the eight disease prototypes when described by negation, against 0.436 for purely positive histological descriptions (``clean vibrant green lamina with smooth intact blade surface''). Omitting negations prevents healthy prototypes from collapsing into disease clusters and reduces false-negative disease escape. We therefore exclude negation in every template and describe healthy tissue strictly using affirmative descriptions (e.g., ``clean green foliage'', ``intact smooth leaf lamina'').

During Phase~0, BioCLIP's text encoder $\phi_{\text{bio,txt}}(\cdot)$ encodes each prompt ensemble, and the results are averaged and $\ell_2$-normalized:
\begin{equation}
    \mathbf{P}_{\text{text}}^{(c)} = \text{Normalize}\left(\frac{1}{M}\sum_{m=1}^M \phi_{\text{bio,txt}}(T_c^{(m)})\right) \in \mathbb{R}^{512}
\end{equation}
The resulting matrix $\mathbf{P}_{\text{text}} \in \mathbb{R}^{C \times 512}$ is cached on device, so there is no runtime tokenization or language-model overhead.

\subsection{Closed-Form Analytical Adaptation via Regularized Fisher-LDA}
\label{sec:fisher_adaptation}

\subsubsection{Multiclass Fisher Linear Discriminant Formulation}
Standard nearest-centroid and cosine-similarity classifiers implicitly assume uniform variance across all feature directions ($\mathbf{\Sigma} = \mathbf{I}$). That assumption does not hold for leaves: shared vegetative structure (such as venation and lamina) creates high-variance directions that mask lesion differences between diseases on the same host. Multiclass Fisher Linear Discriminant Analysis (Fisher-LDA) \cite{fisher1936use, rao1948utilization} resolves this by weighting features by $\hat{\mathbf{\Sigma}}^{-1}$, which down-weights those shared directions and amplifies low-variance directions containing discriminative lesion symptoms.

Fisher-LDA computes a linear projection matrix $\mathbf{W} \in \mathbb{R}^{C \times d}$ and bias vector $\mathbf{b} \in \mathbb{R}^C$ that maximize between-class scatter $\mathbf{S}_B$ relative to within-class scatter $\mathbf{S}_W$:
\begin{equation}
    \label{eq:fisher_weights}
    \mathbf{W} = [\boldsymbol{\mu}_1, \dots, \boldsymbol{\mu}_C]^T \hat{\mathbf{\Sigma}}^{-1}, \qquad
    b_c = -\frac{1}{2}\boldsymbol{\mu}_c^T \hat{\mathbf{\Sigma}}^{-1}\boldsymbol{\mu}_c - \log C
\end{equation}
where $\hat{\mathbf{\Sigma}}$ is the regularized pooled within-class covariance matrix ($d = 896$) and class priors are uniform ($\pi_c = 1/C$).

\subsubsection{Small-Sample Singularity \texorpdfstring{($N \ll d$)}{(N << d)}}
Evaluating Eq.~\eqref{eq:fisher_weights} requires inverting the empirical pooled within-class scatter matrix over all $C = 11$ classes:
\begin{equation}
    \label{eq:within_class_scatter}
    \mathbf{S}_W = \frac{1}{N-C}\sum_{c=1}^C \sum_{\mathbf{z} \in \tilde{\mathcal{S}}_c} (\mathbf{z}-\boldsymbol{\mu}_c)(\mathbf{z}-\boldsymbol{\mu}_c)^T \in \mathbb{R}^{d \times d}
\end{equation}
With $N = 440$ support representations and $d = 896$ features, the support size is far below the feature dimension ($N \ll d$), and the same holds after estimating class means. Here $N - C = 440 - 11 = 429$ is the degrees of freedom left, so the rank of $\mathbf{S}_W$ is bounded:
\begin{equation}
    \label{eq:rank_bound}
    \text{rank}(\mathbf{S}_W) \le \min(d, N-C) = 429 < 896
\end{equation}
Hence, $\mathbf{S}_W$ has a nullity of at least $896 - 429 = 467$: at least 467 of its eigenvalues are zero ($\det(\mathbf{S}_W) = 0$), and it cannot be inverted directly.

\subsubsection{Analytical Ledoit--Wolf Covariance Shrinkage}
\label{sec:shrinkage}
To restore invertibility without manual hyperparameter tuning (such as searching over a grid of ridge penalties $\mathbf{S}_W + \epsilon \mathbf{I}$), we apply analytical Ledoit--Wolf shrinkage \cite{ledoit2004well}, which contracts $\mathbf{S}_W$ toward a spherical target $\nu \mathbf{I}_d$:
\begin{equation}
    \hat{\mathbf{\Sigma}} = (1 - \rho^*)\mathbf{S}_W + \rho^* \nu \mathbf{I}_d, \qquad \nu = \frac{1}{d}\text{Tr}(\mathbf{S}_W)
    \label{eq:lw_target}
\end{equation}
The optimal shrinkage intensity $\rho^* \in (0, 1]$ is determined in closed form by minimizing expected quadratic Frobenius risk:
\begin{equation}
    \rho^* = \min\left(1, \frac{\sum_{i=1}^N \|(\mathbf{z}_i - \boldsymbol{\mu}_{c_i})(\mathbf{z}_i - \boldsymbol{\mu}_{c_i})^T - \mathbf{S}_W\|_F^2}{N^2 \left[\text{Tr}(\mathbf{S}_W^2) - \frac{1}{d}\text{Tr}^2(\mathbf{S}_W)\right]}\right)
    \label{eq:lw_shrinkage}
\end{equation}
This shifts zero eigenvalues to positive values $\tilde{\lambda}_i = (1 - \rho^*)\lambda_i + \rho^* \nu \ge \rho^* \nu > 0$, ensuring that $\hat{\mathbf{\Sigma}}$ is strictly positive-definite and invertible. Its inverse $\hat{\mathbf{\Sigma}}^{-1}$ is solved stably via Cholesky decomposition ($\hat{\mathbf{\Sigma}} = \mathbf{L}\mathbf{L}^T$). Scoring a query $\mathbf{z}$ as $\mathbf{l}_{\text{fisher}} = \mathbf{z}\mathbf{W}^T + \mathbf{b}$ then requires only $C \cdot d$ multiply-accumulate (MAC) operations ($9{,}856$ MACs for $C=11$), requiring minimal on-device computation.

Weighting by $\hat{\mathbf{\Sigma}}^{-1}$ acts as a whitening transform: each eigen-direction with variance $\lambda_i$ is rescaled by $1/\lambda_i$, dampening common leaf morphology while highlighting subtle lesion variations. The condition number
\begin{equation}
    \kappa(\hat{\mathbf{\Sigma}}) = \lambda_{\max}(\hat{\mathbf{\Sigma}}) / \lambda_{\min}(\hat{\mathbf{\Sigma}})
    \label{eq:whitening_spread}
\end{equation}
reflects the dynamic range of this feature rescaling. Because the augmented support views are formed from real leaves, shrinkage guarantees numerical stability across all sample sizes.

\subsection{Adaptive Two-Tier Classification and Edge Deployment}
\label{sec:edge_cascade}

\subsubsection{Tier-1 Fast Path and Shannon Uncertainty Gating}
For an incoming leaf image $\mathbf{x}$, Tier~1 extracts the normalized DINOv2 embedding $\mathbf{f}_{\text{dino}} \in \mathbb{R}^{384}$ and computes fast prototype logits by temperature-scaled cosine similarity against the visual prototypes $\mathbf{P}_{\text{dino}} \in \mathbb{R}^{C \times 384}$:
\begin{equation}
    \label{eq:tier1_logits}
    \mathbf{l}_{\text{dino}} = \gamma \cdot \left(\mathbf{f}_{\text{dino}} \mathbf{P}_{\text{dino}}^T\right), \qquad \gamma = 20.0
\end{equation}
A softmax yields the fast posterior probabilities:
\begin{equation}
    \label{eq:tier1_softmax}
    \mathbf{p}_{\text{dino}} = \text{softmax}(\mathbf{l}_{\text{dino}}) \in \Delta^{C-1}
\end{equation}
Tier~1 uses cosine prototype matching only, with no covariance projection, so the Fisher-LDA computation is spent only on queries that need it. The Tier-1 prediction is $\hat{y}_{\text{tier1}} = \arg\max_c p_{\text{dino}, c}$.

Certainty is scored from the same forward pass, so no extra computation is needed. We combine the top-2 margin and normalized entropy into a confidence score $\mathcal{C}(\mathbf{x}) \in [0, 1]$:
\begin{equation}
    \label{eq:shannon_gate}
    \mathcal{C}(\mathbf{x}) = \left(p_{\text{dino}, (1)} - p_{\text{dino}, (2)}\right) \cdot \left(1.0 - \mathcal{H}_{\text{norm}}(\mathbf{x})\right)_+
\end{equation}
where $p_{\text{dino}, (1)}$ and $p_{\text{dino}, (2)}$ are the top-1 and top-2 posteriors, $(\cdot)_+ = \max(0, \cdot)$, and $\mathcal{H}_{\text{norm}}(\mathbf{x})$ is the normalized Shannon entropy \cite{shannon1948mathematical}:
\begin{equation}
    \mathcal{H}_{\text{norm}}(\mathbf{x}) = -\frac{1}{\log C}\sum_{c=1}^C p_{\text{dino}, c}\log(p_{\text{dino}, c} + \epsilon)
\end{equation}
with $\epsilon = 10^{-12}$ for numerical stability. The rectifier $(\cdot)_+$ simply guards against floating-point round-off. Ambiguous queries with near-uniform posteriors exhibit high entropy ($\mathcal{H}_{\text{norm}} \to 1$) and negligible margin, driving $\mathcal{C}(\mathbf{x}) \to 0$. When $\mathcal{C}(\mathbf{x}) \ge \tau_{\text{conf}}$ ($\tau_{\text{conf}} = 0.35$, calibrated on validation data), Tier~1 accepts the prediction; otherwise, the query escalates to Tier~2.

\subsubsection{Tier-2 Multimodal Consensus Escalation}
When $\mathcal{C}(\mathbf{x}) < \tau_{\text{conf}}$, the query goes to Tier~2. BioCLIP ViT-B extracts $\mathbf{f}_{\text{bio}} \in \mathbb{R}^{512}$, which is concatenated with the Tier-1 embedding to form $\mathbf{z} = [\mathbf{f}_{\text{bio}} \,\|\, \mathbf{f}_{\text{dino}}] \in \mathbb{R}^{896}$. Two posteriors are then computed: the discriminant visual posterior $\mathbf{p}_{\text{fisher}} = \text{softmax}(\mathbf{z}\mathbf{W}^T + \mathbf{b})$ and the taxonomic text posterior $\mathbf{p}_{\text{text}} = \text{softmax}(\gamma \cdot \mathbf{f}_{\text{bio}}\mathbf{P}_{\text{text}}^T)$. These are fused with Fisher consensus weight $w_{\text{lda}} = 0.75$:
\begin{equation}
    \label{eq:multimodal_blend}
    \mathbf{p}_{\text{blend}} = w_{\text{lda}} \, \mathbf{p}_{\text{fisher}} + (1 - w_{\text{lda}}) \, \mathbf{p}_{\text{text}}
\end{equation}
and the final diagnosis is $\hat{y} = \arg\max_c p_{\text{blend}, c}$.

\subsubsection{Soft-Anchored Transductive Recalibration}
\label{sec:transductive}
In 5-shot calibration, each centroid $\boldsymbol{\mu}_c$ is estimated from only five support leaves. Lighting changes, shadows, and symptom progression can shift prototypes between support images and field queries. To adapt without manual labels, confident Tier-2 queries ($\max_c p_{\text{blend}, c} \ge 0.70$) are buffered into a first-in, first-out (FIFO) queue as reference anchors $\mathcal{Q}_{\text{anchor}}^{(c)}$, limited to 20 anchors per class. Verified support samples receive a $3\times$ weight factor so that pseudo-label drift does not shift class centroids away from confirmed disease definitions:
\begin{equation}
    \label{eq:transductive_set}
    \tilde{\mathcal{S}}_c^{\text{trans}} = \tilde{\mathcal{S}}_c^{(3\times)} \cup \mathcal{Q}_{\text{anchor}}^{(c)}
\end{equation}
Once the buffer fills during scouting, centroids $\boldsymbol{\mu}_c^{\text{trans}}$ and pooled scatter matrix $\mathbf{S}_W^{\text{trans}}$ are re-estimated, the shrinkage parameter $\rho^*$ is recomputed, and updated projection parameters $(\mathbf{W}^{\text{trans}}, \mathbf{b}^{\text{trans}})$ are resolved via Cholesky substitution in about 0.53\,s. This runs asynchronously in the background, so Tier~1 keeps operating with static prototypes while later Tier-2 decisions use the updated ones.

Three design choices keep this update stable and efficient. First, the 0.70 confidence threshold ensures high pseudo-label purity ($\approx$98\%) while avoiding the coverage starvation that collapses accuracy at higher thresholds ($\ge$0.80). Second, the support weight anchors class centroids against manifold drift: the original support leaves are repeated $w_{\mathrm{sup}}$ times so that in the re-estimated centroid
$\boldsymbol{\mu}_c^{\text{trans}} = (w_{\mathrm{sup}}\sum_{\mathbf{x}\in\mathcal{S}_c}\mathbf{x} + \sum_{\mathbf{q}\in\mathcal{Q}_{\text{anchor}}^{(c)}}\mathbf{q}) / (w_{\mathrm{sup}}|\mathcal{S}_c| + |\mathcal{Q}_{\text{anchor}}^{(c)}|)$
the verified leaves outvote pseudo-labels, and $w_{\mathrm{sup}}$ is set per deployment rather than fixed globally. With five support leaves per class and up to twenty anchors, $w_{\mathrm{sup}}=3$ keeps a single support leaf worth roughly one and a half confident anchors on the 11-class benchmark, whereas the field protocol, which draws only two anchors per class, uses $w_{\mathrm{sup}}=1$ or $2$ and no confidence threshold because a fixed threshold there leaves too few eligible anchors. Third, the 20-anchor cap bounds update latency while preventing frequent classes from introducing sample imbalance.

\subsection{Two-Tier Quantized Edge Model Packaging and Android Architecture}
\label{sec:packaging}
Agricultural scouting hardware operates under constrained flash storage, and field connectivity is often unreliable \cite{shoaib2023advanced, sharif2026real}. BioDINO-Edge is therefore architected so that diagnosis never touches the network: once installed, every query is processed entirely on-device without streaming, cloud offloading, or server calls. The framework is partitioned into two INT8-quantized Open Neural Network Exchange (ONNX) binaries (footprints reported in mebibytes (MiB), where $1\,\text{MiB} = 2^{20}$ bytes), separating a fast standalone engine from an on-demand deep companion.

\textbf{Tier 1 Standalone Engine} (\path{biodino_mobile_int8.onnx}): Packaged inside an APK (occupying $\approx$22.8\,MB on device, where the base model binary accounts for $\approx$22.0\,MiB on disk and $\approx$15.1\,MiB deflated). It integrates the DINOv2 Small INT8 backbone, calibrated Phase~0 prototypes, and the Shannon confidence gate executed via the ONNX Runtime C++ execution provider. Installing the APK enables immediate offline diagnosis.

\textbf{Tier 2 Companion Module} (\path{biodino_companion_int8.onnx}): The companion engine occupies $\approx$85.3\,MiB on disk, containing the BioCLIP ViT-B INT8 backbone and the 896-dimensional Fisher projection matrix. It is fetched on-demand when high-precision multimodal escalation is requested, functioning completely offline once stored.

Together, both binaries occupy $\approx$107.3\,MiB of flash storage on device.

\section{Experimental Setup}
\label{sec:experiments_setup}

\subsection{Datasets and Diagnostic Pathology Coverage}
\label{sec:datasets}
We evaluate BioDINO-Edge across two foliar pathology benchmarks with contrasting imaging characteristics:

\subsubsection{PlantVillage Controlled Benchmark}
From the standard PlantVillage repository \cite{hughes2012plantvillage}, we build a curated 11-class subset of 9,385 foliar images from three crops: Apple (\textit{Malus domestica}), Grape (\textit{Vitis vinifera}), and Potato (\textit{Solanum tuberosum}). The classes cover healthy foliage and eight diseases: Apple Scab, Apple Black Rot, Apple Cedar Rust, Grape Black Rot, Grape Esca, Grape Leaf Blight, Potato Early Blight, and Potato Late Blight. This setup evaluates fine-grained lesion identification on the same plant species rather than broad crop separation, providing a genuine test of disease discrimination.

For few-shot calibration, five support images per class ($K=5$) are drawn at random (55 in total), while the remaining 9,330 images serve as unseen queries. Neither support nor query images were seen during backbone pre-training.

\subsubsection{PlantDoc In-The-Wild Field Benchmark}
To test robustness under field conditions (sunlight glare, canopy shadows, soil clutter, and overlapping foliage), we use the in-the-wild PlantDoc benchmark \cite{singh2020plantdoc}. We evaluate across 27 shared pathology classes, comprising 2{,}668 training images and 252 field test images, ensuring disjoint support and query splits ($\mathcal{S} \cap \mathcal{Q} = \emptyset$). We test under two evaluation settings:
\begin{itemize}
    \item \textbf{5-way 5-shot episodic:} Following standard few-shot protocols \cite{snell2017prototypical,zhou2026vsf}, we run 50 independent Monte Carlo episodes. In each episode $e$, 5 classes are drawn without replacement ($\mathcal{C}_e \subset \{1, \dots, 27\}$), and the support set $\mathcal{S}_e$ contains 5 labeled leaves per class (25 total) from the training split. The query set $\mathcal{Q}_e$ contains all test images from those 5 classes (averaging 46.7 query leaves per episode).
    \item \textbf{27-way all-class evaluation:} All 27 classes are evaluated simultaneously (where random-guess accuracy is $1/27 \approx 3.70\%$). The model receives 5 support leaves per class (135 total), expanded by 8-view augmentation to $N = 1{,}080$ feature vectors, and scores all 252 field queries in closed form.
\end{itemize}

\subsection{Evaluation Protocols and Safety Metrics}
\label{sec:metrics}
Experiments on PlantVillage are evaluated over 30 independent Monte Carlo episodes with randomized support splits, reporting mean accuracy $\bar{x}$, standard deviation $\sigma$, 95\% confidence intervals (CI; $95\%\,\text{CI} = \bar{x} \pm 1.96 \cdot \sigma / \sqrt{30}$), and peak single-episode accuracy. Because misclassification costs in precision agriculture are asymmetric, we evaluate safety metrics alongside standard accuracy:
\begin{itemize}
    \item \textbf{Top-1 Accuracy and Macro F1-Score:} The F1-score is macro-averaged across all classes to prevent frequent classes from masking errors on smaller or healthy classes.
    \item \textbf{False-Negative Rate:} The proportion of diseased leaves incorrectly classified as healthy, where false-negative (FN) and true-positive (TP) counts define the rate: $\text{FNR} = \text{FN} / (\text{TP} + \text{FN})$.
    \item \textbf{Cross-Species Confusion Rate:} The proportion of queries misattributed to an entirely different botanical family (e.g., classifying a potato leaf as an apple disease).
    \item \textbf{Area Under the Risk--Coverage Curve (AURC):} For selective classification and confidence gating, we evaluate the trade-off between coverage (fraction of queries processed by the gating rule) and selective risk (error rate among accepted queries). The AURC integrates empirical risk across all coverage levels; lower values denote better uncertainty calibration and safer selective triage.
\end{itemize}

To ensure unbiased cross-domain evaluation, shared parameters ($\gamma = 20.0$, $w_{\text{lda}} = 0.75$, and $\tau_{\text{conf}} = 0.35$) were calibrated strictly on independent PlantVillage validation episodes and applied to PlantDoc without re-tuning. The transductive buffer is adapted to the smaller test volume of PlantDoc (252 total queries across 27 classes): the buffer retains confident predictions capped at two anchors per class, preventing buffer starvation while maintaining high pseudo-label purity. We report both static inductive and transductive results across all benchmarks to separate baseline feature discrimination from dynamic adaptation gains.

\textbf{Engineering interpretation of baseline performance.} As shown in Table~\ref{tab:comparative}, standard distance matching loses accuracy when applied directly to high-dimensional biological representations without covariance regularization. Zero-shot BioCLIP and Tip-Adapter struggle because general text prompts do not resolve subtle necrotic lesions on leaves. Standard Prototypical Networks provide a competitive baseline, but weighting all 896 embedding dimensions equally leaves predictions vulnerable to background leaf veins and surface glare. In contrast, BioDINO-Edge uses Ledoit--Wolf regularized Fisher-LDA projection (Section~\ref{sec:shrinkage}) to suppress common vegetative variance, improving inductive accuracy by $+1.80$ percentage points (pp) over the centroid baseline. Adding transductive anchor recalibration further increases accuracy to 97.41\% (a $+4.13$\,pp gain over standard nearest-centroid matching). While server-trained few-shot models in the agricultural literature (e.g., MAFDE-DN4~\cite{zhao2024mafde}, SC-FSL~\cite{mu2024few}, AgriFewNet~\cite{babu2025agrifewnet}, and VSF~\cite{zhou2026vsf}) report 5-shot accuracies between 81.4\% and 94.8\% on PlantVillage, they require GPU backpropagation during training; BioDINO-Edge achieves higher accuracy entirely on edge CPUs over frozen backbones.

Running Laplacian propagation in the Fisher-projected subspace drops accuracy by 5.7\,pp (from 98.49\% down to 92.84\%). This drop occurs because Fisher-LDA projects the 896 dimensions onto $C-1$ discriminant axes to maximize global class separation, which removes the fine-grained local neighborhood manifold that graph Laplacian smoothing relies on.

This section evaluates the operational robustness and sensitivity of BioDINO-Edge across three core practical dimensions: (i) confidence gating and selective routing trade-offs between latency reduction and diagnostic safety (Table~\ref{tab:tier_routing}, Figs.~\ref{fig:risk_coverage}--\ref{fig:tau_sensitivity}); (ii) hyperparameter stability during continuous field streaming (Table~\ref{tab:transductive_sensitivity}); and (iii) the impact of multi-view support generation on Ledoit--Wolf shrinkage and covariance conditioning (Table~\ref{tab:aug_sensitivity}).

\textbf{Uncertainty gating and selective routing.} Table~\ref{tab:tier_routing} details the tier-separated performance and routing policies across 30 benchmark episodes. Under the deployed operating threshold ($\tau=0.35$), the dual-metric gate routes 14.02\% of queries through the 59.78\,ms Tier-1 fast path (Panel~a). The remaining 85.98\% of queries escalate to the deeper Tier-2 multimodal stage, achieving 96.98\% accuracy. Compared to running the full Tier-2 pipeline on every leaf (164.52\,ms), cascaded routing lowers average latency to 149.84\,ms while matching full-stream diagnostic accuracy (97.36\%).

Table~\ref{tab:tier_routing}(b) sweeps the gating threshold $\tau$ to demonstrate why $\tau=0.35$ is the optimal operating point. Aggressive thresholds ($\tau \le 0.20$) yield fast-exit rates up to 61.76\% and lower latency, but cause Tier-1 accuracy to drop below 99\%, allowing diseased leaves to escape undetected. Conversely, conservative thresholds ($\tau \ge 0.50$) ensure 100\% Tier-1 accuracy, but drop fast-exit coverage to only 5.15\%, forfeiting latency gains. Setting $\tau = 0.35$ strikes the ideal trade-off, saturating Tier-1 accuracy at 99.84\% while preserving a 14.07\% fast-exit rate and saving $\approx$15\,ms per diagnosis.

\section{Discussion and Practical Limitations}
\label{sec:discussion}

\subsection{Operational Edge Deployment Considerations}
BioDINO-Edge is engineered for operational deployment on resource-constrained agricultural edge platforms, including handheld scouting terminals, tractor-mounted spray booms, and unmanned aerial vehicles (UAVs). By eliminating iterative backpropagation, the framework avoids GPU memory spikes and on-device training heat, executing feed-forward inference and closed-form linear algebra directly on ARM CPUs. Under sustained continuous load, thermal throttling stabilizes execution throughput at 4.26\,FPS (Section~\ref{sec:edge_hardware}). Therefore, field deployment is best structured around shutter-triggered, on-demand inspections rather than continuous video streams. Furthermore, the modular two-tier architecture enables rapid over-the-air deployment of the lightweight base application ($\approx$22.8\,MB), allowing companion multimodal modules to be downloaded on demand when cellular bandwidth permits.

\subsection{Limitations and Future Research Directions}
\textbf{Canopy clutter and leaf segmentation.} BioDINO-Edge processes foliar images at the individual leaf frame level. In unsegmented field imagery with dense, overlapping canopies, multiple leaves from neighboring plants can enter the camera field of view, lowering gating confidence. While tight lesion cropping degrades host context, processing unsegmented canopy clutter introduces irrelevant background vectors. Future work could incorporate leaf segmentation to isolate individual leaves before closed-form classification.

\textbf{Statistical pseudo-replication in support expansion.} Multi-view support expansion generates correlated pseudo-replicates. Because the analytical Ledoit--Wolf shrinkage intensity assumes i.i.d.\ sampling, the nominal $N-C=429$ degrees of freedom overstate the independent information in the support set (effective sample size: 55--440). Although the sensitivity study in Section~\ref{sec:aug_sensitivity} shows that downstream accuracy remains stable across view counts and augmentation modes, a cluster-aware shrinkage estimator that explicitly accounts for within-image dependence remains an important theoretical direction.

\textbf{Attention artifacts in frozen backbones.} Frozen vision transformers can exhibit attention artifacts on non-symptomatic structures like veins or petioles \cite{darcet2024vision}. Because Fisher-LDA operates on pooled representations downstream, it does not alter internal backbone attention; the framework targets whole-leaf diagnosis rather than pixel-level lesion localization.

\textbf{Optical degradation and focus blur.} Severe defocus or motion blur degrades fine lesion textures, reducing diagnostic accuracy. The Android client screens frames before diagnosis with two lightweight guards: the maximum cosine similarity between the DINOv2 embedding and the class prototypes must exceed 0.12 for the frame to count as foliage, and the mean luminance of a 64$\times$64 center crop must exceed 22/255 for it to count as illuminated. If either check fails, the application suppresses the diagnosis to prevent false predictions on uninformative frames. An additional discrete-Laplacian variance check (threshold 45) detects motion blur, prompting the user to hold the camera steady when frames are blurred rather than issuing an uncertain diagnosis. While the uncertainty gate routes ambiguous clear foliage to Tier-2, handling optical degradation relies on these front-end guards.

\textbf{Scope and threats to validity.} The physical edge profiling in this work was conducted on a single physical device (Samsung Galaxy S24~FE) with CPU-only INT8 ONNX Runtime; absolute latency and memory will vary across mobile SoCs, though the underlying algorithmic complexity remains hardware-independent. In few-shot evaluation, BioDINO-Edge is designed specifically for streaming, sequential edge inference rather than batch transduction over pre-collected query pools. Finally, while PlantDoc evaluates robustness on unconstrained field foliage with target-domain support, fully unsupervised cross-domain transfer (e.g., PlantVillage$\rightarrow$PlantDoc without target support), quantitative image-quality stress tests, and multi-device profiling remain future research directions.

\section{Conclusion and Future Directions}
\label{sec:conclusion}

This paper presented \textbf{BioDINO-Edge}, an on-device few-shot framework for foliar plant disease diagnosis that operates without gradient computation or backpropagation. By coupling frozen vision foundation models (DINOv2 Small) with botanical vision--language encoders (BioCLIP ViT-B/16), the architecture forms a joint 896-dimensional descriptor capturing localized lesion morphology alongside taxonomic context. Regularized Fisher-LDA with Ledoit--Wolf shrinkage resolves the small-sample covariance singularity ($N \ll d$), completing one-time parameter adaptation across all 11 classes in 533.99\,ms on an ARM64 CPU without iterative training. At runtime, per-query diagnosis requires only 59.78\,ms through the Tier-1 fast path, with the dual-metric Shannon-margin uncertainty gate escalating ambiguous foliage to multimodal consensus to achieve an average per-query latency of 149.84\,ms. Across 30 benchmark episodes, BioDINO-Edge achieved 97.41\% $\pm$ 0.71\% accuracy on PlantVillage with a 0.702\% false-negative rate, and reached 84.22\% $\pm$ 11.24\% in 5-way 5-shot field evaluation on PlantDoc (50.79\% across all 27 classes simultaneously), demonstrating efficient, real-time diagnostic capability on commodity edge hardware.

\subsection{Future Directions}
Building upon the operational findings of this work, future research will pursue two primary directions. First, we plan to deploy and benchmark the gradient-free pipeline on low-cost embedded single-board computers, such as Raspberry Pi platforms, to support stationary in-field monitoring stations and automated scouting traps. Second, we aim to develop blur-robust feature extraction and restoration modules to elevate diagnostic accuracy on optical frames degraded by severe wind-induced canopy motion or camera defocus. Additionally, integrating BioDINO-Edge into the closed-loop controller of an autonomous robotic sprayer for selective, variable-rate nozzle actuation represents a promising pathway toward automated precision crop protection.

\subsection{Models and Hyperparameters}
Frozen backbones: DINOv2 ViT-S/14 (\texttt{timm} \path{vit_small_patch14_dinov2}, 384-D) and BioCLIP ViT-B/16 (\texttt{open\_clip} \path{hf-hub:imageomics/bioclip}, 512-D); joint feature $z=[\,\text{bio}\,\|\,\text{dino}\,]\in\mathbb{R}^{896}$. Fixed constants: logit scale $\gamma=20.0$, Fisher blend $w_{\text{lda}}=0.75$, routing gate $\tau=0.35$; transductive support weight $3\times$, max anchors 20/class, confidence threshold 0.70 on PlantVillage and the buffer settings stated in Section~\ref{sec:metrics} for PlantDoc; Tip-Adapter $\alpha=1.0,\beta=5.5$. Fisher-LDA uses Ledoit--Wolf shrinkage (\texttt{sklearn LDA solver=lsqr, shrinkage=auto}). The estimator applies Ledoit--Wolf per class in standardized feature space and pools the shrunk within-class covariances with class priors; the augmentation sensitivity study (Section~\ref{sec:aug_sensitivity}) reports the mean per-class intensity. At 5-way 1-shot the raw support has $N=C=5$ and the within-class scatter vanishes; we resolve the singularity with a data-driven ridge floor (mean support feature variance) added to the Ledoit--Wolf covariance, which reduces Fisher to regularized nearest-centroid (the correct degenerate limit). For $N>C$ the canonical sklearn estimator is used unchanged.

\textbf{Three solver paths for one estimator.} The paper uses three implementations of the same regularized discriminant. Section~\ref{sec:shrinkage} presents the estimator analytically as a pooled scatter matrix solved by Cholesky factorization. The Python reference implementation uses \texttt{scikit-learn} with \texttt{solver=lsqr} and automatic Ledoit--Wolf shrinkage. The Android client implements dense Cholesky factorization using EJML. These are mathematically equivalent formulations of the same model: \texttt{lsqr} solves the identical normal equations via conjugate gradients rather than explicit factorization, converging to the pooled Ledoit--Wolf solution within machine precision. The computational latencies in Table~\ref{tab:adaptation_breakdown} (332.00\,ms Cholesky decomposition; 51.31\,ms projection solve) reflect the deterministic dense execution path deployed on the physical mobile device. The FP32/INT8 comparison in Table~\ref{tab:quantization} verifies agreement between these paths: under identical splits and constants, the discrepancy between implementations is at most 0.40\,pp across all evaluation benchmarks.
