# Data and Code Availability Statement

The complete mobile application, model export scripts, and evaluation benchmarks will be released in a public repository upon acceptance. The PlantVillage dataset is openly available at https://plantvillage.psu.edu/, and the PlantDoc benchmark is available at https://github.com/pratikkayal/PlantDoc-Dataset.

For the journal's research-data policy (Option C), a permanent archived release (e.g., Zenodo DOI) of the code, exported ONNX models, and evaluation scripts should be created before or at acceptance.

Suggested statement once the DOI exists:

> The code, exported ONNX models, and evaluation scripts are archived at Zenodo under DOI: `10.5281/zenodo.XXXXXXX`.
